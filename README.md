# Lucas Mol - Portfólio Pessoal 🚀

Bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para apresentar minhas habilidades, projetos, formação e experiências como Engenheiro de Software com foco em Produto e Estrategista de Growth.

## 🛠 Tecnologias Utilizadas

O projeto foi totalmente reescrito utilizando uma stack moderna e focada em alta performance e incrível experiência de usuário (UX):

- **[Next.js](https://nextjs.org/)**: Framework React (App Router) para renderização eficiente e excelente SEO.
- **[React](https://react.dev/)**: Biblioteca JavaScript para construção de interfaces de usuário.
- **[TypeScript](https://www.typescriptlang.org/)**: Superconjunto de JavaScript que adiciona tipagem estática, garantindo código mais seguro.
- **[Tailwind CSS v4](https://tailwindcss.com/)**: Framework CSS utilitário para uma estilização ágil, responsiva e alinhada ao design premium ("Glassmorphism").
- **[Framer Motion](https://www.framer.com/motion/)**: Biblioteca poderosa para criar animações fluidas de entrada, transições ao rolar a tela e micro-interações.
- **[Lucide React](https://lucide.dev/)**: Pacote de ícones SVG leves e altamente customizáveis.

## ✨ Destaques do Projeto

- **Animações Dinâmicas:** Animação de fundo no Hero simulando uma "chuva digital" (feita puramente com a API Canvas do HTML5 e React) e elementos que surgem suavemente ao fazer o scroll.
- **Arquitetura Componentizada:** Código altamente modular organizado em componentes (`Hero`, `Projetos`, `Sobre`, `Contato`, etc.) para fácil manutenção e escalabilidade.
- **100% Responsivo:** O layout se adapta perfeitamente a dispositivos móveis, tablets e monitores ultrawide.
- **Scroll Spy:** Navegação inteligente que detecta qual seção o usuário está lendo no momento.

## 🚀 Como Executar Localmente

Siga os passos abaixo para rodar o projeto na sua máquina:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/molz3ra/portifolio-atualizado.git
   ```

2. **Acesse o diretório do projeto:**
   ```bash
   cd portifolio-atualizado-main
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. **Acesse no navegador:**  
   Abra [http://localhost:3000](http://localhost:3000) e pronto!
